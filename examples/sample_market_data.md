## 4. 读这份示例时要注意

- `data_status` 只会是 `delayed` / `stale` / `unknown` / `unavailable`，不会出现 `realtime`。
- 期货代码（`GC=F` / `CL=F` / `BZ=F`）返回的是**期货合约参考价**，不是现货价格。
- 价格为 `—` 表示该数据源本次没有取到值，原因写在「备注 / 来源」列，不会用 0 填充。
- 服务器在 60 秒（报价）/ 300 秒（历史）内会命中缓存，`from_cache=true`，但行情时间不变。
