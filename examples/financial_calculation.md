# 示例：金融公式计算（真实营收 CAGR 与现金流质量）

| FY2022 | 2021-09-26 → 2022-09-24 | 394,328,000,000 | 99,803,000,000 | 122,151,000,000 | 10,708,000,000 |

## 2. 营收 CAGR

- 起止：FY2022（394,328,000,000）→ FY2025（416,161,000,000）
- 间隔年数 n = 3（首尾报告期之间）
- 公式：CAGR = (ending / beginning) ** (1 / years) - 1
- 结果：**1.81%**（value=1.812536，status=`ok`）
- 说明：以 3 年复利口径计算。
